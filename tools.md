 <summary><b>Вброс 1:</b></summary><br>

<p>PyInstaller собирает только из выбранной системы: Windows (.exe), Linux и macOS (.app)<br>
Кросс-компиляции нет: сделать файл для Mac, сидя на Windows, нельзя</p>

<h4>Как это обойти на Windows:</h4>
<ul>
  <li>Для Linux: запустить сборку внутри WSL или Docker.</li>
  <li>Для macOS: компилировать на виртуалке Mac или через GitHub Actions</li>
</ul>

<h4>Можно ли собрать бесплатно через GitHub Actions?</h4>
<ul>
  <li>Да, это бесплатно для публичных (открытых) репозиториев без ограничений по минутам</li>
  <li>Для приватных дают 2000 бесплатных минут в месяц</li>
</ul>

<h4>Нюансы для macOS:</h4>
<ul>
  <li>Только актуальные ОС: собирать нужно на современной версии macOS, иначе бинарник не запустится на новых Mac.</li>
  <li>Обязательная подпись: код нужно подписать сертификатом разработчика Apple (Code Signing) и пройти нотаризацию, иначе система заблокирует запуск</li><br>
</ul>
</details>

<p><b>* Pandoc</b> — крошечная консольная программа (один .exe файл весом в несколько мегабайт)<br>
Она берёт один конкретный файл и переводит его в другой формат. Пример команды:</p>

<pre><code>pandoc README.md -o index.html</code></pre>

<p>Мгновенно создаст html в этой же папке. Без разворачивания движков и генерации лишних папок<br>
Сразу можно скормить файл style.css, чтобы он зашил его внутрь / подключил к документу.</p>

<hr>

<p><b>* Jekyll</b> — огромный набор (пакет) скриптов, написанный на динамическом языке программирования Ruby<br>
Его можно установить на Windows\Linux и собирать репозиторию локально без интернета.<br>
В твоём случае, сборка репозитории == проход по папкам и конвертация readme.md > index.html</p>

<details>
<summary>на Windows:</summary><br>
<ol>
  <li>Сначала скачать и установить RubyInstaller (интерпретатор языка Ruby для Windows)</li>
  <li>Вместе с ним установятся инструменты разработчика (MSYS2 и DevKit), чтобы компьютер умел собирать системные библиотеки</li>
  <li>Затем через специальный менеджер пакетов ввести команду: <code>gem install jekyll</code></li>
  <li>Компьютер скачает сотни мелких файлов и скриптов в системные папки Ruby</li><br>
</ol>
</details>
<br>

<p>Jekyll локально гораздо «капризнее»: если обновится Windows или версия Ruby, эта цепочка скриптов<br>может легко сломаться, и её придётся пересобирать заново.</p>

<p>А Pandoc сломать невозможно, т.к. автономен и не зависит от окружения вашей системы</p>

<p><b>* Bash-команды (sed, cat, tr)</b> универсальны как язык автоматизации, потому что все серверы в интернете<br>(GitHub, GitVerse, Рег.ру) работают на Linux, где Bash является стандартом по умолчанию.</p>

<p>Чтобы прогнать инструкцию .yml на Windows без установки Docker,<br>можно использовать программу Git (в папке Git Bash):<br>

— Создать батник:</p>

<pre><code>"C:\Program Files\Git\bin\bash.exe" -c "sed -n '/run: |/,/^[ ]*#/p' .github/workflows/main.yml | sed 's/^[ ]*run: |//' | bash"</code></pre>
