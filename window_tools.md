## непроверенная мной инфа, просто вброс:

~ PyInstaller собирает только из выбранной системы: Windows (.exe), Linux и macOS (.app)
Кросс-компиляции нет: сделать файл для Mac, сидя на Windows, нельзя

### Как это обойти на Windows:
Для Linux: запустить сборку внутри WSL или Docker.
Для macOS: компилировать на виртуалке Mac или через GitHub Actions

### Можно ли собрать бесплатно через GitHub Actions?
Да, это бесплатно для публичных (открытых) репозиториев без ограничений по минутам
Для приватных дают 2000 бесплатных минут в месяц

### Нюансы для macOS:
Только актуальные ОС: собирать нужно на современной версии macOS, иначе бинарник не запустится на новых Mac.
Обязательная подпись: код нужно подписать сертификатом разработчика Apple (Code Signing) и пройти нотаризацию, иначе система заблокирует запуск
